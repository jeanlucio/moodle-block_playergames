# 📖 Usage

## For Administrators

1. Turn on **editing mode** on the site front page or Dashboard.
2. Use **"Add a block" → PlayerGames** to place the widget.
3. Click the avatar to equip a different one, the ❓ icon for a quick explanation, or the 🕐
   icon for the full activity history.

> 💡 **Recommendation:** this block is designed for the **site front page and the Dashboard**, not
> for individual courses (that role belongs to `block_playerhud`). For the widget to become visible
> automatically to everyone:
>
> * Add it to the **site front page** while editing — the front page is shared by the whole site,
>   so this alone makes it visible to every user with a single action.
> * Add it to the **default Dashboard page** (*Site administration → Appearance → Default Dashboard
>   page*) so new dashboards start with it. Existing users who already customised their own
>   Dashboard will not get it retroactively unless you also use *"Reset Dashboard for all users"* —
>   a destructive action that resets everyone's personal Dashboard layout, so use it deliberately.

## For Students

1. The block appears automatically on the site front page and/or the Dashboard once an
   administrator adds it.
2. Click the avatar thumbnail to open the avatar collection and equip a different one.
3. Click the ❓ icon for a short explanation of XP, avatars and rankings.
4. Click the 🕐 icon to open the full activity history log.
5. Toggle "Show in ranking" directly from the block — no need to visit the full Player Hub.
